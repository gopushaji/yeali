Publishing settings

Publishing commits your changes straight to the GitHub repository that hosts the site. You need a fine-grained personal access token: on GitHub go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token, give it access to only this repository with Contents: Read and write permission. The token is stored only in this browser.

Store settings

Site-wide details. Leave the announcement empty to hide the banner at the top of the shop. These save with your draft and go live when you press Publish to site.

Products

Changes are saved as a draft in this browser as you type. Nothing is visible to customers until you press Publish to site. The first photo of each product is the cover image in the shop; extra photos appear as a carousel.
